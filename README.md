# Algorithms — Personal Implementations

This repository contains my personal implementations of various algorithms and data structures, developed as part of my studies and personal interests.

The implementations are based on different sources, including:

- **Personal interests:** Algorithms and data structures I find interesting and want to explore in greater depth.
- **Introduction to Algorithms:** Exercises and implementations inspired by *Introduction to Algorithms* by Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein.
- **University coursework:** Exercises and assignments related to topics covered in my university courses.

## Disclaimer

This is a personal study repository. The implementations are primarily intended for educational purposes and experimentation, rather than as production-ready software.
